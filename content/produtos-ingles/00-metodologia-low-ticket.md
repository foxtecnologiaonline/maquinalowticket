# Metodologia Low Ticket — Inglês (Hotmart Style)

> Documento de referência da Factory para a vertical **Inglês**. Usar como input padrão do `FactoryEngine` (campo `templateId: 'ingles-low-ticket'`) para os 3 produtos definidos em `01`, `02` e `03`.

## 1. Princípio Central: Regra 60/40

O produto **gratuito (isca/front-end)** entrega **60% do conteúdo** — suficiente para gerar uma vitória rápida real e provar que o método funciona. O produto **pago (core/back-end)** entrega os **100% do conteúdo**, incluindo os 40% que resolvem o problema por completo (o "último degrau").

Regra prática de corte dos 60%:
- Entregar o **diagnóstico** e o **primeiro resultado tangível** (ex: 20 frases prontas, 1 simulação de entrevista).
- Nunca entregar o **sistema completo/repetível** — isso é o gancho para o pago.
- O grátis deve gerar a pergunta: *"Se isso já funcionou, o que mais eu destravo pagando?"*

## 2. Sistema de Vendas em Linha Reta (Straight Line)

Toda LP e sequência segue a mesma progressão, sem desvios:

1. **Atenção** (hook de dor específica, não genérica)
2. **Identificação** ("é você que...")
3. **Agitação da dor** (custo de não resolver AGORA)
4. **Vislumbre do novo estado** (a transformação, não a informação)
5. **Prova/Autoridade** (depoimento, número, mecanismo único)
6. **Mecanismo Único** (por que isso funciona quando outras coisas falharam)
7. **Oferta** (o que entrega + bônus + garantia)
8. **Escassez/Urgência real** (vagas, preço, bônus por tempo)
7. **CTA único** — um só botão, uma só ação possível na tela.

Regra: nunca dois CTAs concorrentes na mesma página. Nunca "pensar" como opção — sempre "comprar agora" vs. "sair".

## 3. Gatilhos Mentais Obrigatórios (usar no mínimo 5 por LP)

| Gatilho | Onde usar |
|---|---|
| Escassez | Vagas/preço promocional com prazo real |
| Urgência | Contador de tempo, próxima turma, bônus expira |
| Prova Social | Prints de depoimentos, nº de alunos, avaliação |
| Autoridade | Mini-bio do criador ligada à dor específica |
| Reciprocidade | O grátis entrega valor real antes de pedir venda |
| Novidade/Mecanismo Único | "Método X" nomeado, diferente do "jeito tradicional" |
| Dor vs. Prazer | Comparar custo de não agir vs. ganho de agir |
| Compromisso/Consistência | Micro-compromissos no free (checklist, quiz) |

## 4. Estrutura de Preço (Low Ticket)

- **Isca gratuita**: e-mail/WhatsApp em troca de PDF/mini-aula (custo zero, ativo de captura).
- **Tripwire**: R$ 29–47 (produto de entrada, baixa fricção, alta conversão).
- **Core offer**: R$ 97–197 (produto principal, 100% do conteúdo).
- **Order bump**: +R$ 27–37 no checkout (ex: pack de áudios, cola de bolso).
- **Upsell pós-compra**: R$ 97–297 (mentoria em grupo, correção de redação/simulados).

## 5. Funil Padrão (aplicado aos 3 produtos)

```
Anúncio (Google/Meta) → Landing Page (captura) → Página de Obrigado + Entrega do 60%
   → Sequência de e-mail/WhatsApp (5 a 7 dias) → Oferta do Core (40% restante)
   → Checkout com Order Bump → Upsell → Sequência de reengajamento (carrinho abandonado)
```

## 6. Checklist de Produção por Produto

- [ ] Avatar e dor nomeada (1 frase)
- [ ] Isca gratuita (60%) roteirizada
- [ ] Produto pago (100%) com módulos
- [ ] Copy completa da LP (headline → CTA)
- [ ] 5–7 e-mails/WhatsApp de nutrição + venda
- [ ] 3 anúncios Google Search (RSA) + 3 anúncios Meta
- [ ] Lista de keywords (intenção comercial + informacional)
- [ ] Página de checkout com order bump
- [ ] Depoimentos/prova social (placeholder até ter reais)
